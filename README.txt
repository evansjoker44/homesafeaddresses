IMPORTANT: ACTIVATE THE EMAIL FORM
The website uses FormSubmit to send requests to homesafeaddresses@yahoo.com.
1. After the website is live, submit one test request through the form.
2. Open homesafeaddresses@yahoo.com.
3. Look for the FormSubmit activation email (also check Spam/Junk).
4. Click the activation/confirm link.
5. Submit another test request and verify it arrives.

The website has two contact paths:
- Email My Service Request: emails the completed form to homesafeaddresses@yahoo.com.
- Text Shawn Instead: opens a text message to (408) 444-0469 on supported devices.

GITHUB PAGES
1. Create a public GitHub repository.
2. Upload the FILES INSIDE this folder, not the ZIP itself.
3. Go to Settings > Pages.
4. Choose Deploy from a branch, main, /(root), then Save.
5. In Pages settings, use homesafeaddresses.com as the custom domain.
6. Follow GitHub's DNS instructions in Namecheap and enable Enforce HTTPS when available.
