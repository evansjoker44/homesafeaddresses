HomeSafe Website
================

This folder contains a simple one-page website for HomeSafe Professional Curb Address Painting.

Business details currently included:
- $25 flat rate per curb
- Call or text Shawn: (408) 444-0469
- Serving San Jose and surrounding areas
- HomeSafeAddresses.com

HOW TO PREVIEW
1. Open index.html in Chrome, Edge, Safari, or Firefox.
2. Test the Request Curb Painting form on a phone. Tapping the button opens a text to Shawn with the customer's details.

FREE PUBLISHING OPTION: GITHUB PAGES
1. Create a free GitHub account at github.com.
2. Create a new public repository named homesafe-site.
3. Upload index.html and the assets folder.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /root folder, then Save.
7. GitHub will give you a temporary website address.
8. In Settings > Pages, enter HomeSafeAddresses.com under Custom domain.
9. GitHub will show the DNS records to add in Namecheap. Add those records in Namecheap under Domain List > Manage > Advanced DNS.
10. Once the domain connects, turn on Enforce HTTPS.

IMPORTANT
- The form opens the visitor's texting app. It does not store customer information in a database.
- Test the phone number and text form before sharing the website publicly.
- Replace the sample before/after image with real job photos when available.
